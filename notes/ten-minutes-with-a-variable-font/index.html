Ten minutes with a variable font

02.08.20266 min read

The SERAQUIM wordmark on the front page of this site moves. Point at it and the letters nearest the cursor widen while the others give way, so the word always spans the page exactly. It started as a ten-minute test and turned into the site's signature.

Width as a material

Most variable fonts get used for one thing: picking a weight without loading another file. That's useful, but it treats the font as a menu. The more interesting move is to treat an axis — width, here — as something that can respond to people.

The rule was simple: the total width of the word can't change. If one letter grows, the rest have to make room. That constraint is what makes it feel like a single object rather than eight letters misbehaving.

What went wrong first

  • Width isn't perfectly linear. Doubling the width value doesn't double the letter, so the word slowly shrank as you moved. A small horizontal correction each frame fixed it.
  • Changing weight at the same time was too much. It looked like the word was shouting. Width alone was enough.
  • On phones there's no cursor, so the effect simply doesn't run. A still word is better than a gimmick.

The lesson is an old one: one behaviour, done carefully, beats five done loudly.
